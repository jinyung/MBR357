Motif discovery with EM

We know the DNA sequences, but not where the common motif occurs. Expectation–maximization alternates between estimating motif locations and updating the motif probability matrix.

1. Initialize the model

Model: exactly one motif per sequence (OOPS); fixed width; forward strand only; uniform background (0.25 per base); uniform prior over start positions; no pseudocounts. The seed favors A, C, G, T in order (0.55 vs 0.15). Random initialization can reach different local optima.

Initialize PWM→E-step→M-step↺

2. Current motif profile

Each column sums to 1. Stacks represent nucleotide frequencies, not information content.

3. E-step: Where is the motif?

Use the current PWM to calculate the probability of every possible motif start. Keep all candidates, not just the highest-scoring one.

Score(s) = P(b₁,1) × P(b₂,2) × ... × P(bₖ,k)
Weight(s) = Score(s) / Sum of scores over all starts in that sequence
Why can we ignore the background here?

For a sequence of length L, the probability of the whole sequence given start s is Score(s) × 0.25L−k. The start prior is 1/(L−k+1). Both factors are constant across possible starts and cancel when calculating the posterior weights.

4. M-step: What does the motif look like?

Each candidate contributes fractional counts according to its E-step weight. Add these counts across all sequences and normalize each column.

Count(b,j) = Sum of weights of candidates with base b at column j
New P(b,j) = Count(b,j) / Number of sequences

5. Convergence

Each complete EM iteration improves or maintains the observed-data log-likelihood, up to numerical precision. Convergence does not guarantee the global optimum or the biological motif.

Log-likelihood calculation
log L = Σᵢ log [0.25^(Lᵢ−k) × (Σₛ Scoreᵢ(s))/(Lᵢ−k+1)]

This is the likelihood of the complete observed DNA dataset, summing over the unknown start position independently in each sequence.

Try these experiments

  1. Run one E-step. Check that the weights for each sequence sum to 1.
  2. Inspect a weighted count, then run the M-step. Explain why the PWM changes.
  3. Run ten iterations. Compare the motif and likelihood with the initial model.
  4. Try random initialization several times. Do the runs converge to the same motif?
  5. Try a different motif width or enter your own sequences.
